# IRUMI Language Support (拡張機能)

<p align="center">
  <img src="icon_v2.png" width="128" alt="IRUMI Logo" />
</p>

日本語本来の思考順序で書けるスクリプト言語 **「IRUMI (イルミ)」** の公式VS Codeエディタ拡張機能です。
VS Code、Antigravity IDE、VSCodium 等に対応し、最高峰の開発体験を提供します。

---

## 🌟 主な機能

* **シンタックスハイライト（完全網羅）**
  * 全角・半角カッコ `（ ）` `()`、文字列、数値・回数、真偽値（`真` `偽` `True` `False` 等）を視認性高く色分け。
  * 制御構文（`もし` `なら` `ちがえば` `繰り返す` `試す` `設計図` `関数` `覚える` 等）、組み込み命令（`書く` `聞く` `足す` `変換` `絞り込む` `外部呼出` 等）、助詞（`を` `に` `へ` `と` `で` `から` `まで` `各` 等）を正確にハイライト表示。
* **便利なコードスニペット**
  * 頻出構文のコードスニペットを搭載。キー入力時に補完候補として呼び出せます。
* **日本語入力（IME）に配慮した自動補完**
  * 全角カッコ `（` を入力すると、自動で閉じカッコ `）` がペアで補完されます。
  * `#` や `＃` によるコメントアウト（`Cmd + /` / `Ctrl + /`）に対応。
* **言語自動認識**
  * `.ir` および `.irumi` ファイルを開くと、自動的に IRUMI 言語モードとして認識されます。

## 💡 搭載スニペット一覧

プレフィックスを入力して Tab / Enter を押すだけで基本構文を展開できます：

| プレフィックス | 説明 | 展開例 |
| :--- | :--- | :--- |
| `もし` / `if` | 条件分岐 | `（もし （条件） なら 処理 ちがえば 処理）` |
| `関数` / `fn` | 関数定義 | `（関数名 （引数） （処理） 関数）` |
| `設計図` / `class` | クラス定義 | `（クラス名 （初期化引数） （処理） 設計図）` |
| `繰り返す-範囲` | 範囲ループ | `（1 から 10 まで 各 i （処理） 繰り返す）` |
| `繰り返す-各要素` | 各要素ループ | `（リスト の各要素を 要素 （処理） 繰り返す）` |
| `試す` / `try` | 例外処理 | `（処理 失敗したら エラー内容 （例外処理） かならず （最終処理） 試す）` |

## 📖 コード記述の基本ルール

IRUMI は **SOV（日本語語順: 目的語 ➔ 動詞）** で動作します。カッコの**末尾が「命令」**になります。

### 1. 文字を表示する
```lisp
（"こんにちは、IRUMI！" を 書く）
```

### 2. 計算（四則演算）
```lisp
（10に 20を 足す）        # => 30
（100から 30を 引く）     # => 70
（5に 8を 掛ける）        # => 40
（50を 5で 割る）         # => 10
```

### 3. 変数を覚える
```lisp
（名前 "アリス" を 覚える）
（（"ようこそ、" 名前 足す "さん！" 足す） を 書く）
```

### 4. 条件分岐（もし 〜 なら 〜 ちがえば）
```lisp
（点数 85 を 覚える）
（もし （点数 80 以上） なら
    "合格おめでとう！" を 書く
ちがえば
    "また次回がんばろう！" を 書く）
```

### 5. ループ（繰り返し）
```lisp
# 範囲ループ (1〜5)
（1から 5まで 各 カウント （
    （（"第" カウント "回目" 足す） 書く）
） 繰り返す）

# 各要素ループ
（くだもの （"りんご" "みかん" "ぶどう"） 覚える）
（くだもの の各要素を 要素 （
    （（"おいしい " 要素 足す） 書く）
） 繰り返す）
```

### 6. 関数を作る
```lisp
（挨拶 （相手） （
    （（"こんにちは、" 相手 足す "さん！" 足す） を 書く）
） 関数）

（"タロウ" で 挨拶 呼ぶ）
```

### 7. 設計図（クラス）とエラー処理
```lisp
# クラス定義
（勇者 （名前） （
    （名前 名前 覚える）
） 設計図）

# 例外処理
（
    （10を 0で 割る）
失敗したら エラー内容 （
    （（"エラー: " エラー内容 足す） 書く）
） 試す）
```

## 🚀 使い方・実行方法

### 1. IRUMI 本体のインストール
* **macOS / Linux (Homebrew)**:
  ```bash
  brew install IRUMI163/irumi/irumi
  ```
* **Windows (PowerShell)**:
  ```powershell
  irm https://raw.githubusercontent.com/IRUMI163/homebrew-irumi/main/install.ps1 | iex
  ```
* **Windows / macOS / Linux 共通 (Python pip)**:
  ```bash
  pip install git+https://github.com/IRUMI163/homebrew-irumi.git
  ```

### 2. コードの作成と実行
1. VS Code で `.ir` または `.irumi` ファイル（例: `main.ir`）を作成・編集します。
2. 日本語で自然にコードを記述します。
3. ターミナルで実行します：
   ```bash
   irumi main.ir
   ```
