## なぜ IRUMI なのか？（言語の哲学）

多くのプログラミング言語は英語の語順（SVO: 主語 ➔ 動詞 ➔ 目的語）をベースに設計されています。  
しかし、日本語を母国語とする人々の自然な思考は **SOV（主語 ➔ 目的語 ➔ 動詞）** です。

```text
英語の思考 (Python/JS):   print("こんにちは")       [動詞 ➔ 目的語]
日本語の思考 (IRUMI):     （"こんにちは" を 書く）   [目的語 ➔ 動詞]
```

IRUMI（イルミ）は、**「人間が頭の中で考える順番のままコードを書く」** ことを徹底的に追求したスクリプト言語です。

### 4つの特徴

1. **日本語本来の語順（SOV: 目的語 ➔ 動詞）**
   カッコの**最後が「命令（動詞）」**になります。「10に 20を 足す」「お名前を 聞く」と、日本語の文章を書く感覚で自然にプログラムが組み立てられます。
2. **IMEストレスフリー（全角・スペース不要対応）**
   日本語入力（全角）をオンにしたまま作業できます。全角カッコ `（ ）`、全角数字 `１０`、全角クォート `” ”`、全角コメント `＃` に完全対応。単語の間にスペースを入れなくても、助詞を認識して自動分割して動きます。
3. **カッコ1つの極限のシンプル構文**
   覚える記号は丸カッコ `（ ）` だけです。波カッコ `{}` や角カッコ `[]`、コロン `:` やセミコロン `;` の使い分けに悩む必要はありません。
4. **Python のパワーをそのまま使えるフル機能**
   四則演算はもちろん、もし文、ループ、配列・辞書、自作関数、クラス設計図、エラー処理、ファイル読み書き、そして Python の標準・外部ライブラリを直接呼び出せる強力な相互運用性を備えています。

## インストール方法

### 1. Homebrew (macOS / Linux)
Homebrew をお使いの場合、ターミナルで以下のコマンドを実行するだけでインストールできます：

```bash
# ワンライナーで直接インストール
brew install IRUMI163/irumi/irumi
```
または：
```bash
brew tap IRUMI163/irumi
brew install irumi
```

### 2. Windows (PowerShell ワンライナー)
Windows の場合は、PowerShell で以下の1行を実行するだけで自動インストールされ、環境変数 PATH も設定されます：

```powershell
irm https://raw.githubusercontent.com/IRUMI163/homebrew-irumi/main/install.ps1 | iex
```

### 3. Python pip を使う方法 (Windows / macOS / Linux 共通)
Python 3 がインストールされている環境であれば、`pip` を使って一発でインストールできます（`irumi` コマンドが自動登録されます）：

```bash
pip install git+https://github.com/IRUMI163/homebrew-irumi.git
```

### 4. 手動インストール / Git
```bash
git clone https://github.com/IRUMI163/homebrew-irumi.git
cd homebrew-irumi

# macOS / Linux の場合:
chmod +x irumi
# パスの通った場所に配置（例: ~/.cargo/bin や /usr/local/bin）

# Windows の場合:
# カレントディレクトリで irumi.cmd をそのまま実行、または PATH に追加
.\irumi.cmd main.ir
```

#### インストールの確認
```bash
irumi -v
# => IRUMI v1.0.1
```

## 3つの基本ルール

IRUMI のルールはたったの3つです。

```text
① 「（ 」ではじめて「 ）」でおわる
② さいごに「やりたいこと（命令）」を書く
③ スペースを空けずに書いても動く！
```

## 10分クイックチュートリアル

### 1. 文字の表示と計算
```lisp
# 画面に文字を表示する
（"こんにちは、IRUMIの世界へ！" を 書く）

# 足し算（カッコで囲んで、末尾に命令）
（（10に 20を 足す） 書く）        # => 30

# 文字の結合も「足す」で対応
（（"山田" と "太郎" を 足す） 書く）  # => 山田太郎
```

### 2. 変数を覚える（代入）
```lisp
# 「（変数名 値 覚える）」で変数に記憶します
（点数 85 覚える）
（目標 80 覚える）

（（"現在の点数は " 点数 "点です" 足す） 書く）
```

### 3. キーボードからの入力（対話）
```lisp
（お名前 （"あなたのお名前は？: " 聞く） 覚える）
（（"ようこそ、" お名前 "さん！" 足す） 書く）
```

### 4. 条件分岐（もし 〜 なら 〜 ちがえば）
```lisp
（もし （点数 目標 以上） なら
    "おめでとう！目標達成です！" を 書く
ちがえば
    "あと少し！次はがんばろう！" を 書く）
```

### 5. 繰り返し（ループ）
```lisp
# 回数を指定して繰り返す
（3回 （"わーい！" 書く） 繰り返す）

# 1から5まで数えながら繰り返す（範囲ループ）
（1から 5まで 各 カウント （
    （（"第" カウント "回目" 足す） 書く）
） 繰り返す）
```

### 6. リスト（配列）と辞書（連想配列）
```lisp
# リストの作成と取り出し
（くだもの （"りんご" "みかん" "ぶどう"） 覚える）
（（くだもの 0 番目） 書く）   # => りんご

# 辞書（キーと値のペア）
（ユーザー （
    （"名前" "アリス"）
    （"年齢" 20）
    （"職業" "魔法使い"）
） 辞書 覚える）

（（ユーザー "名前" 取る） 書く）  # => アリス
```

### 7. 自分で関数を作る
```lisp
（税込み計算 （値段） （
    （値段 1.1 掛ける）
） 関数）

（支払額 （1000 税込み計算） 覚える）
（（"お支払い金額：" 支払額 "円" 足す） 書く）  # => 1100.0円
```

## 言語仕様完全リファレンス

### 1. 入出力・基本操作
| 命令 | 日本語の例 | 説明 |
| :--- | :--- | :--- |
| **書く / 表示** | `("文字" 書く)` | 画面に改行付きで出力します |
| **ログ** | `(データ ログ)` | `［ログ］ データ` の形式で出力します |
| **聞く / 入力** | `("質問文" 聞く)` | コンソールから1行文字列を受け取ります |
| **覚える / 設定**| `(変数名 値 覚える)` | 変数に値を代入します |
| **待つ** | `(1.5 待つ)` | 指定秒数スリープします |
| **おわり** | `("終了します" おわり)`| プログラムを即座に終了します |

### 2. 計算・数値演算
| 命令 | 例 | 戻り値 |
| :--- | :--- | :--- |
| **足す / ＋** | `(10 20 足す)` | `30`（数値の加算、文字列の連結、リストの結合） |
| **引く / −** | `(100 30 引く)` | `70` |
| **掛ける / かける / ＊** | `(5 8 掛ける)` | `40` |
| **割る / わる / ／** | `(20 4 割る)` | `5.0` |
| **整除 / //** | `(20 3 整除)` | `6` |
| **べき乗 / ** / ^** | `(2 3 べき乗)` | `8` |
| **余り / あまり / ％** | `(10 3 余り)` | `1` |
| **絶対値 / abs** | `(-15 絶対値)` | `15` |
| **四捨五入 / round** | `(3.1415 2 四捨五入)`| `3.14` |
| **最大 / max** | `(10 20 最大)` | `20` |
| **最小 / min** | `(10 20 最小)` | `10` |

### 3. 比較・論理演算
| 命令 | 例 | 戻り値 |
| :--- | :--- | :--- |
| **等しい / 同じ / ＝** | `(10 10 等しい)` | `真 (True)` |
| **厳密等 / ＝＝＝** | `(1 1.0 厳密等)` | `偽 (False)` |
| **違う / 異なる / ≠** | `(10 20 違う)` | `真 (True)` |
| **大きい / より大きい / ＞**| `(20 10 大きい)` | `真 (True)` |
| **小さい / より小さい / ＜**| `(5 10 小さい)` | `真 (True)` |
| **以上 / ≧** | `(10 10 以上)` | `真 (True)` |
| **以下 / ≦** | `(10 20 以下)` | `真 (True)` |
| **かつ / AND** | `(真 偽 かつ)` | `偽 (False)` |
| **または / OR** | `(真 偽 または)` | `真 (True)` |
| **ではない / NOT** | `(真 ではない)` | `偽 (False)` |

### 4. 文字列操作
| 命令 | 例 | 説明 |
| :--- | :--- | :--- |
| **分ける** | `("りんご,みかん" "," 分ける)` | 指定区切り文字でリストに分割 |
| **つなぐ** | `(リスト "," つなぐ)` | リストを指定文字で連結 |
| **含む** | `("プログラミング" "グラ" 含む)` | 文字列が含まれているかを判定 (`True`/`False`) |
| **置き換える** | `("晴れの日" "晴れ" "雨" 置き換える)`| 文字列の置換 |
| **文字数** | `("イルミ" 文字数)` | 文字の長さ（`3`） |
| **数値化** | `("123" 数値化)` | 文字列を数値型に変換 |
| **文字化** | `(123 文字化)` | 数値を文字列型に変換 |

### 5. リスト・辞書操作
| 命令 | 例 | 説明 |
| :--- | :--- | :--- |
| **番目 / 取る** | `(リスト 0 番目)` | インデックス位置の要素を取得 |
| **追加** | `(リスト "新しい要素" 追加)` | リストの末尾に要素を追加 |
| **挿入** | `(リスト 1 "要素" 挿入)` | 指定位置に要素を挿入 |
| **消す** | `(リスト 0 消す)` | 指定位置の要素を削除 |
| **長さ** | `(リスト 長さ)` | 要素数を取得 |
| **並び替える** | `(リスト 並び替える)` | 昇順ソート |
| **逆順** | `(リスト 逆順)` | 順序を反転 |
| **辞書** | `(((キー 値)...) 辞書)` | 辞書（連想配列）を作成 |
| **設定** | `(辞書 "キー" 値 設定)` | 辞書のキーの値を更新 |

### 6. 制御構文・ループ
```lisp
# 回数ループ
（5回 （"ループ中" 書く） 繰り返す）

# 範囲ループ (1から10まで)
（1から 10まで 各 i （
    （（i 2 余り 0 等しい） なら （i 書く） もし）
） 繰り返す）

# 条件ループ (while)
（カウント 0 覚える）
（（カウント 5 小さい） 間 （
    （（"カウント：" カウント 足す） 書く）
    （カウント （カウント 1 足す） 覚える）
） 繰り返す）

# 配列要素のループ (foreach)
（くだものリスト （"りんご" "バナナ" "ぶどう"） 覚える）
（くだものリスト の各要素を くだもの （
    （（"おいしい " くだもの 足す） 書く）
） 繰り返す）
```

### 7. 設計図（オブジェクト指向 / クラス）

    （名前 名前 覚える）

## ターミナル CLI コマンド

IRUMI は日本語コマンド・英語コマンドの両方に対応しています。

```bash
# ファイルの実行
irumi main.ir
irumi 実行 main.ir
irumi run main.ir

# 対話モード (REPL) の起動
irumi 対話
irumi repl

# 新規プログラムファイルのひな形を自動作成
irumi 作る ゲーム.ir
irumi new ゲーム.ir

# 1行だけ即座にコードを評価
irumi -c "（（10に20を足す）書く）"

# バージョン表示
irumi バージョン
irumi -v

# ヘルプ表示
irumi 使い方
irumi -h
```

## エディタ対応 (VS Code / Antigravity IDE)

IRUMI はエディタ拡張機能を提供しています。

* **構文ハイライト**: キーワード、文字列、数値を識別して色分け
* **全角カッコ補完**: 全角の `（` を入力すると自動で `）` が閉じる設計
* **言語自動判別**: `.ir` または `.irumi` ファイルを開くだけで自動適用

### インストール方法
ターミナルからインストールできます：
```bash
code --install-extension irumi-language-1.0.0.vsix
```
*Antigravity IDE の場合は、拡張機能タブの「…」から「VSIX からのインストール」を選択してください。*
